# Рецепты build123d для FDM

Решения, отработанные на практике (build123d 0.12, OCP 7.9; сборка через cadgen из плагина
text-to-cad — опционально). Импорт: `import build123d as bd` (в моделях cadgen — `from cadgen import build123d as bd`).

## Окружение и экспорт
- cadgen 0.5.0 требует `cadquery-ocp<8`; venv через `uv venv --python 3.12`.
- STL писать `bd.export_stl(shape, path, tolerance=0.01, angular_tolerance=0.2)` — сетка cadgen `@stl` бывает
  с открытыми швами. Проверка: `trimesh.load(p).is_watertight`.
- Не использовать резьбы `bd_warehouse` и helix-sweep — невалидные тела; конструкции без винтовых поверхностей.
- `bd.extrude(bd.Plane.YZ * sketch, L)` может уйти в −X → всегда `dir=(1, 0, 0)`.
- Гейт cadgen видит только прямые импорты модели → после правки общего lib-хелпера пересобирать `--force`.

## Капля для горизонтального отверстия (ось X, вершина вверх)
```python
def teardrop_hole(d, length, apex_deg=90, flat_top=False):
    r = d / 2
    h = r / math.sin(math.radians(apex_deg / 2))      # высота вершины над осью
    t = r * math.cos(math.radians(apex_deg / 2))       # точки касания
    z_t = r * math.sin(math.radians(apex_deg / 2))
    prof = bd.Circle(r) + bd.Polygon((-t, z_t), (t, z_t), (0, h), align=None)
    if flat_top:
        prof = prof & bd.Rectangle(2 * r, 2 * r * 1.15)   # срез вершины → короткий мост
    return bd.extrude(bd.Plane.YZ * prof, length, dir=(1, 0, 0))
```

## Разрезное кольцо со звёздочкой
8 лучей (полигон корень/вершина), скругления вершин 0,3 и корней 0,5 через `bd.fillet` на 2D-вершинах,
конусные заходы 1 мм с обоих торцов, разрез — `Box` по впадине. Параметры: `tip_d` (Ø по вершинам),
`wall`, `split_w`, `split_angle`. Для стержней Ø10–12 с разбросом диаметра: tip_d 10, wall 1,5, split 3 (защёлка — 7,5).

## Горизонтальное кольцо на киле
- Кольцо: `Rot(90,0,0) * (Rot(0,90,0) * collar)` → ось X, разрез вверх.
- Киль «ласточкин хвост»: `t = R·0.7071`, ось на `AXIS_Z = 2t − KEEL_W/2`; полигон
  `(-t, z_t), (t, z_t), (KEEL_W/2, 0), (-KEEL_W/2, 0)` минус `Circle(R)` → грани 45° касательно в кольцо.
- Потолок отверстия: треугольник `(-h, z0+h), (h, z0+h), (0, z0+2h)`, `h = tip_r·0.7071` — вычесть.
- Воронка на разрезе: трапеция от `split_w` вниз на 1,5 мм под 45° — вычесть.

## Кольцо в клетке
Кольцо → зазор 1,2 → клетка (стенка ≥1,6). Связь только шейкой напротив разреза. Утолщение стенки под
потай без прилива: наружный круг клетки `Pos(bulge/2,0)*Cylinder(r_cage + bulge/2)` — стенка плавно
1,6 → 1,6+bulge к стороне винта.

## Скруглённая шейка/перемычка к круглому телу
```python
closed = bd.offset(bd.offset(disc + web, f, kind=bd.Kind.ARC), -f, kind=bd.Kind.ARC)  # морф. закрытие
shape = (closed - bd.Pos(*c) * bd.Circle(r - 0.3)) & keep   # keep — только сторона перемычки
```
Перемычку начинать от центра круга (иначе 2D offset падает на коротких рёбрах).
Скругление всех углов плоского контура (снежинка): тот же двойной офсет `+r,−r` затем `−r,+r`.

## Винт с потаем
Цилиндр Ø3,2 до грани + `Cone(3.2/2, 5.9/2, depth)` у грани + цилиндр Ø5,9 наружу на 1 мм;
`depth = (5.9−3.2)/2`. Ось X: `Rot(0,90,0)`.

## Коническая крыша над гибким кольцом
Снаружи: юбка 1,5 → конус 45° → площадка. Внутри (вычесть после всех добавлений, включая бобышки на
крыше): конус 45° от внутреннего радиуса клетки до потолка Ø8 — единственный мост.

## Проверки
```bash
cadgen step inspect validate STEP/part.step --format text
python <cad-plugin>/skills/dfam-check/scripts/dfam_tool.py measure STL/part.stl --angle-limit 45   # опционально
```
В отчёте DfAM: `flat-down` грани < 30° — реальные свесы; 45° ровно — норма; тонкие «стенки» на краю
потая/фаски — артефакт лучевого замера.
